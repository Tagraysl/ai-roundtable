WEB CONNECTION

继续使用你的 AI 网页

Claude 默认使用手动接力，无需安装扩展。开始讨论后按提示复制内容和交回回复即可。下面的自动网页桥仅适用于提供方明确允许自动化访问的其他网站。

  1. 安装网页桥（只需一次）

    在 Chrome 打开 chrome://extensions，或 Edge 打开 edge://extensions。启用「开发者模式」，点击「加载已解压的扩展程序」，选择下面打开的 extension 文件夹。

  2. 打开 AI 网页并登录

    仅连接你已经确认允许自动访问的网站；Claude 网页不接入自动桥。

  3. 连接当前标签页

    复制连接码，点击浏览器工具栏中的「同桌 AI 网页桥」，粘贴并选择成员，然后点击「连接当前标签页」。软件每次启动后更新一次连接码。

登录和验证码在原网站完成。已有网页草稿不会被自动覆盖。
