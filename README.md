# 同桌 AI · AI Roundtable

**让不同的 AI，在同一张桌上协作。**

[English](README.en.md)

面向 Windows 的本地 AI 协作应用。用一个模型继续工作，或拖动积木，让多个模型分别规划、分析、审查和汇总。聊天记录与协作方式分开管理，下次打开时可以在原对话中换一个模型或工作流继续。

**0.11.6 · 预发布测试版**。MIT 开源，独立开发，不隶属于任何模型服务商。

## 下载与启动

**推荐普通用户下载 `AI-Roundtable-0.11.6-Setup-x64.exe`**：双击打开安装向导，选择安装目录，保留桌面快捷方式选项，安装后从桌面启动。默认按当前用户安装，无需管理员权限。卸载保留聊天与设置文件；安装版不会自动导入其他文件夹中便携版的数据。

也可以选择下面的 ZIP 便携版：

1. 打开本仓库 **Releases**，下载名称包含 **windows-x64.zip** 的文件。“Code → Download ZIP” 是源码，不是可直接运行的软件。
2. **完整解压**到自己可写的目录，例如文档中的 `AI-Roundtable` 文件夹。
3. 双击 **AI-Roundtable.exe**。保留旁边的文件和文件夹，不能只复制 EXE。无需安装 Node.js。
4. 在成员设置中配置自己的 API 连接，或连接本机 Codex；网页模型使用手动复制、粘贴接力。

桌面快捷方式：解压后双击 **Create-Desktop-Shortcut.cmd**，或在软件设置中点击“创建桌面快捷方式”。快捷方式使用程序当前图标，支持含空格及中文的路径。移动程序文件夹后，请从新位置重新创建。不要在压缩包内部运行。

适用于 Windows x64。安装包与便携包未进行代码签名，暂无自动更新。请从本仓库下载，分别核对 INSTALLER-SHA256SUMS.txt 或 SHA256SUMS.txt，不要禁用系统安全防护。无需注册本软件账号。

## 功能

- **单模型与工作流**：同一讨论中选择使用方式；独立选择接续、重新开始或部分历史与资料。
- **可视化协作**：串行、并行、汇合、人工确认、执行、最终输出节点；每个 AI 节点可选择连接及具体模型。
- **按依赖恢复**：节点失败不会取消无关分支。重试所选节点，复用已完成结果，满足依赖后继续；另一失败节点需分别处理。
- **职责与模板**：快捷职责可组合、取消、编辑，保存自定义工作流。
- **资料与记录**：本地保存聊天及附件；支持图片、PDF 和常见 Office 文档的有限解析，导出结果。
- **界面设置**：玻璃风格、浅色/深色、配色与字体，中英文界面。

| 接入 | 支持范围 |
| --- | --- |
| API | OpenAI Chat Completions、Anthropic Messages 兼容协议；使用自己的地址、密钥和模型 |
| Codex | 需本机安装并登录；普通节点只读，执行节点在指定目录获得用户许可后工作 |
| 网页模型 | 手动把提示复制到网站，再把回答粘贴回来；不会自动操控网站 |

API 节点生成内容，**不会直接在电脑上执行代码**。可让 API 模型编写代码，再让 Codex 执行节点保存、运行并验证。权限、视觉能力、延迟和费用以提供商为准。

通用终端接入与自动网页接入目前停用。不支持任意循环和自动条件分支。联网工具需另外配置，并不代表所有模型具有原生搜索能力。

## 数据、隐私与升级

聊天、设置与附件默认保存于程序旁的 `data`，可以在设置中迁移。密钥通过 Windows 账户加密，不是云端同步，换电脑后可能需要重新输入。运行任务时，选中的历史与资料会发送给所选模型服务；本地保存不等于完全离线。

发布脚本从全新目录按白名单构建，不包含开发者的密钥、聊天、附件或网页登录数据。自己的 `data`、`instance`、`data-location.json` 不要上传 GitHub 或随程序分享。

升级时退出程序，备份当前目录及自定义数据目录，将新版本解压到另一个空目录。默认位置用户在首次启动前复制旧 `data` 文件夹；使用自定义位置还需保留旧 `data-location.json`。保留旧版本备份，确认记录正常后再整理。不要在程序运行时复制数据；跨 Windows 账户需重新输入密钥。

## 开发与持续发布

源码在仓库，可执行程序在 Releases。Node.js 22+ 下运行：

```powershell
node --test tests/*.test.cjs
./scripts/release.ps1 -Download
node scripts/verify-release.cjs
# 用已校验的便携 ZIP 生成安装版，替换为本次构建的实际路径
./scripts/build-installer.ps1 -PortableZip "dist/release-<id>/AI-Roundtable-0.11.6-windows-x64.zip" -DownloadCompiler
```

核心测试不需要第三方依赖。构建下载并校验固定版本 Electron，产物位于 `dist/release-<随机标识>/`。GitHub Actions 在推送与拉取请求时测试和构建，维护者检查产物后将 ZIP 与校验文件放入版本 Release。后续通过提交、分支和 Pull Request 迭代，并更新 package.json 版本与发布说明。

本地开发可执行 `npm install`、`npm start`。架构见 [ARCHITECTURE.md](ARCHITECTURE.md)。Electron/Chromium、PDF.js 和 JSZip 保留各自许可证，见运行包与 `third-party`。

## 已知限制与反馈

测试通过不代表全部环境没有问题。部分后端错误与系统对话框仍可能显示中文；自定义名称和聊天内容不翻译。超长上下文会裁剪，附件解析没有 OCR，模型可能无法读取所有格式。API 重试不保证不重复计费；部分输出不会自动重发。提供商与 Codex 连接依赖用户环境。
